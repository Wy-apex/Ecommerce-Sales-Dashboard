# 实验2：数据看板的设计与实现

## 一、实验名称

实验2：数据看板的设计与实现

实验项目：电商销售数据分析看板

开发语言：Python

开发工具：Visual Studio Code

主要技术：Streamlit、Pandas、Plotly

## 二、实验目的

本次实验主要是学习数据看板的设计与实现方法，了解如何将数据处理、统计分析和可视化展示结合起来，完成一个简单的数据分析系统。

通过本次实验，掌握使用 Pandas 读取和清洗数据的方法，学习使用 Plotly 绘制统计图表，并使用 Streamlit 将图表和数据指标整合到网页中。

同时，通过增加商品类别、销售地区和日期范围筛选功能，进一步了解交互式数据看板的基本实现过程。

## 三、实验内容与需求分析

### 1. 业务场景选择

本次实验选择电商销售数据分析作为应用场景。

在电商销售过程中，通常需要了解商品销售情况、不同地区的销售差异以及销售额随时间的变化情况。

因此，我决定设计一个电商销售数据看板，对模拟销售记录进行统计分析，并通过图表展示结果。

本项目所有销售数据均为 Python 生成的模拟数据，不是真实企业的经营数据。

### 2. 看板功能需求

根据实验要求，我将数据看板划分为四个主要区域。

| 区域 | 主要内容 | 实现方式 |
|---|---|---|
| 数据概览区 | 销售总额、订单总数、平均客单价、月度增长率 | Streamlit 指标卡片 |
| 销售维度统计区 | 商品类别销售额、地区销售占比 | Plotly 柱状图、环形图 |
| 销售趋势分析区 | 月度销售额变化 | Plotly 折线图 |
| 销售明细区 | 展示订单详细数据 | Streamlit 数据表格 |

另外，在网页左侧设置筛选栏，支持商品类别、销售地区以及日期范围筛选。

### 3. 页面布局设计

看板采用单页布局。

页面顶部显示标题与数据概览，中部展示销售维度统计图表，下方展示月度销售趋势，最后展示订单明细与 CSV 下载按钮。

筛选功能统一放在左侧边栏，方便用户根据不同条件查看销售数据。

这样的布局能够让用户先了解总体情况，再逐步查看详细分析结果。

## 五、实验过程

### 1. 模拟数据生成

首先，我编写了 `generate_data.py` 文件，用于生成电商销售模拟数据。

程序使用 Python 的 `random`、`datetime` 和 `csv` 等模块，随机生成订单编号、日期、商品类别、商品名称、地区、商品数量和销售单价。

本次实验共生成 600 条模拟销售记录，并额外加入一条重复记录。

为了测试数据清洗功能，我还特意设置了四条存在异常值或缺失值的记录。

最终生成 601 条原始记录，保存到 `data/sales_raw.csv` 文件中。

### 2. 数据清洗与处理

完成原始数据生成后，我编写了 `clean_data.py`，使用 Pandas 对数据进行预处理。

首先读取原始 CSV 文件，并检查字段是否完整。

接着处理数据中存在的问题，包括缺失值、日期格式错误、无效商品数量、无效销售单价以及重复记录。

完成清洗后，根据商品数量和单价计算销售额：

**销售额 = 商品数量 × 商品单价**

同时从订单日期中提取月份，为后面的销售趋势分析做准备。

清洗后的数据保存到 `data/sales_clean.csv`。

实际清洗结果如下：

| 项目 | 数值 |
|---|---:|
| 原始数据量 | 601 条 |
| 删除异常及重复记录 | 5 条 |
| 清洗后有效记录 | 596 条 |
| 销售总额 | 286,626.14 元 |

通过数据清洗，保证了后续统计和可视化所使用的数据更加合理。

### 3. 数据可视化图表设计

完成数据准备后，我使用 Plotly 绘制销售统计图表。

首先使用横向柱状图展示不同商品类别的销售额，并按照销售额大小进行排列，方便比较不同类别的销售表现。

接着使用环形图展示不同地区的销售额占比，方便观察地区之间的销售差异。

最后使用折线图展示月度销售额变化情况，以便观察不同月份的销售趋势。

通过这三类图表，实现了分类比较、占比分析和趋势分析等基本的数据可视化功能。

### 4. Streamlit 数据看板整合

在 `app.py` 中使用 Streamlit 创建网页，并将数据指标和统计图表整合到同一个页面。

数据概览区通过 `st.metric()` 显示销售总额、订单总数、平均客单价和最近月度增长率。

销售维度统计区分别显示商品类别横向柱状图和地区销售额环形图。

销售趋势分析区通过折线图展示月度销售情况。

销售明细区则通过 `st.dataframe()` 展示订单数据。

程序通过以下命令启动：

`python -m streamlit run app.py`

启动后，可以在浏览器中通过 `http://localhost:8501` 查看数据看板。

### 5. 交互功能实现

为了让数据看板更加方便使用，我增加了三种筛选功能，分别为商品类别筛选、地区筛选和日期范围筛选。

用户修改筛选条件后，程序会使用 Pandas 重新筛选数据，并更新销售指标、图表和明细表格。

此外，我还使用 `st.download_button()` 添加 CSV 数据下载功能，允许用户将筛选后的销售记录保存到本地。

## 七、实验中遇到的问题及解决方法

### 1. Streamlit 程序启动问题

一开始，我直接点击 VS Code 中的 Python 运行按钮执行 `app.py`，终端出现了 `missing ScriptRunContext` 提示，网页无法按照预期正常启动。

后来了解到，Streamlit 需要使用专门的命令启动 Web 服务。

改为执行 `python -m streamlit run app.py` 后，成功在浏览器中打开数据看板。

### 2. 程序文件位置错误

在创建项目文件时，我曾将 `app.py` 放入 `data` 文件夹，导致 Streamlit 提示找不到程序文件。

后来将 `app.py` 移动到项目根目录，问题得到解决。

### 3. 数据指标与图表排版问题

第一次运行看板时，由于浏览器窗口宽度较小，顶部部分指标显示不完整。

后来调整浏览器窗口大小，销售总额、订单数量等指标便可以完整展示。

此外，最初柱状图上的数据标签较为拥挤，后来将竖向柱状图改为横向柱状图，使销售额对比更加直观。

### 4. 日期显示格式问题

最初销售明细中的日期包含 `00:00:00`，影响表格的整洁性。

后来通过 Pandas 的 `strftime("%Y-%m-%d")` 将日期转换为年月日格式，使日期显示更加清晰。

### 5. 单个月份趋势图显示问题

当筛选结果只包含一个月份时，Plotly 的横坐标出现不合理的时间刻度。

后来将月份设置为分类坐标轴，并使纵坐标从 0 开始，成功解决了显示问题。
